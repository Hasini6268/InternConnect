# InternConnect

InternConnect is a web-based internship management platform that connects students with companies. Students can explore internships, apply for opportunities, upload resumes, and track application status. Companies can post internships and manage applicants.

## Features

### Student
- User registration and login
- Browse available internships
- Apply for internships
- Track applications
- Resume upload

### Company
- Company login
- Post internships
- View applicants
- Update application status

### Admin
- Manage users
- Monitor platform activities

## Technology Stack

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express.js

Database:
- MongoDB

Authentication:
- JWT
