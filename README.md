# InternConnect 🚀

InternConnect is a full-stack internship management platform that connects students and companies through a single digital platform.

The platform helps students discover internship opportunities, apply for internships, upload resumes, and track their application status. Companies can create internship postings, view applicants, and manage the recruitment process.

---

## 📌 Project Objective

The main objective of InternConnect is to simplify the internship searching and hiring process by providing a platform where:

- Students can find suitable internship opportunities.
- Companies can post internship openings.
- Students can apply and track their applications.
- Companies can manage and evaluate applicants.

# ⚙️ Installation and Setup

## Clone Repository

```
git clone https://github.com/Hasini6268/InternConnect.git
```

---

## Backend Setup

Go to backend folder:

```
cd backend
```

Install dependencies:

```
npm install
```

Create a `.env` file:

```
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key
```

Start backend server:

```
npm start
```

Backend runs on:

```
http://localhost:5000
```

---

## Frontend Setup

Open the frontend folder.

Run the project using:

- VS Code Live Server extension

or open the HTML files directly in the browser.
